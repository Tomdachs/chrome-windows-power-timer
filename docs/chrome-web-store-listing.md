# Chrome Web Store listing draft

This document is the source of truth for the first Chrome Web Store submission.

## English

**Name**

Windows Power Timer

**Summary**

Schedule Windows sleep or shutdown from Chrome with a simple one-minute countdown.

**Detailed description**

Windows Power Timer adds a small power countdown to the Chrome toolbar. Choose a duration, select Sleep or Shut down, and let Chrome trigger the requested Windows power action when the timer expires.

Main features:
- Set a countdown from 1 minute up to 7 days.
- Choose Windows Sleep or Shut down.
- Use 5m, 15m, 30m, and 1h presets.
- See the remaining time and cancel at any time.
- Shutdown requires confirmation before the timer starts.
- No account, telemetry, advertising, or cloud service.

A small companion Native Messaging host must be installed on Windows. It is open source and available from the project's GitHub Releases.

## Japanese

**名前**

Windows Power Timer

**概要**

Chromeから1分単位でWindowsのスリープまたはシャットダウンを予約できるシンプルな電源タイマーです。
**詳細説明**

Windows Power Timerは、ChromeのツールバーからWindowsの電源操作を予約するための小さなカウントダウンタイマーです。時間を指定し、スリープまたはシャットダウンを選ぶと、期限到達時にWindowsへ電源操作を依頼します。

主な機能:
- 1分から7日までのカウントダウン
- スリープ / シャットダウンを選択
- 5分 / 15分 / 30分 / 1時間のプリセット
- 残り時間表示とキャンセル
- シャットダウン開始前の確認
- アカウント、テレメトリ、広告、クラウドサービスなし

Windows側には小さなNative Messaging companion hostのインストールが必要です。hostはオープンソースで、GitHub Releasesから入手できます。
